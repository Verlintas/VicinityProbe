# VicinityProbe

[![License: GPL-3.0-or-later](https://img.shields.io/badge/License-GPL--3.0--or--later-blue.svg)](LICENSE)

用手机上的各种传感器和系统模块,按规范采集周边环境数据,生成带质量评估、原始样本存档和频谱分析的测量报告。

> **AI 生成说明**:本代码库大部分由 AI 编程工具辅助生成,用于生产或安全敏感场景前请自行审查。

[English](README.md) · [探测体系文档](docs/PROBES.zh-CN.md) · [真机验收清单](docs/TESTING.md) · [贡献指南](CONTRIBUTING.md) · [安全政策](SECURITY.md)

## 功能

- **测量目录(96 项)**:每项探测都是正式的 `ProbeSpec` 条目,写明被测量、SI 单位、标称采样率、量程——覆盖运动、环境物理量、磁场、生物信号、声学、定位与卫星、无线电、电气、系统资源、设备信息、上下文事件
- **能力预检**:开始前先检查设备支持情况(✅ 可用 / ⚠️ 缺权限 / ❌ 无硬件),自己挑要测的项目
- **数据质量门禁**:每项测量给出 EXCELLENT/GOOD/DEGRADED/FAILED 等级,附带采样覆盖率和实际采样率,原因码可机读
- **专业统计**:每个通道输出 min/max/mean/stddev/RMS/CV,以及 p1/p5/p25/p50/p75/p95/p99 分位数
- **统计推断**:最小二乘线性趋势(斜率 + R² + 显著性 p 值)、自相关周期检测、偏度/峰度 —— 已接入趋势图与振动分析
- **传感器融合**:互补滤波(加速度+陀螺 → 姿态角)、倾斜补偿航向角、磁力计硬铁偏移最小二乘拟合(球心拟合)
- **传感器去噪**:滚动中值滤波(去尖峰)、指数滑动平均、一维卡尔曼滤波 —— 实时监测带"平滑"开关
- **声学**:AudioRecord 直接采 PCM,算 LAeq / Lpeak / L10 / L50 / L90;**声级记录器**(分钟级 LAeq 柱状图、时段统计、70dB 参考线、CSV 导出)
- **频谱分析**:自带 Radix-2 FFT(Hann 窗),输出主导频率、频谱平坦度、频带能量、**谱峰检测**(抛物线插值)、**谐波分析 THD%**(2f–8f)
- **振动分析**:主导频率 / RMS / 峰值因子 / THD / 周期性 / ISO 2631 近似分级
- **原始样本存档**:所有数值通道都落盘成 CSV(`samples/<probeId>/channel_<ch>.csv`)
- **报告导出**:JSON + Markdown + ZIP(报告和原始样本一起打包)
- **历史与对比**:报告存档、重命名、删除,两份报告逐项对比
- **免 root 抓包**(VPNService):协议统计(TCP/UDP/ICMP)、连接流表(五元组/字节/状态)、DNS 查询域名、**RFC 6066 精确 SNI 提取**、HTTP 明文请求解析、**JA3 风格 TLS 客户端指纹**、**应用层协议识别**(DNS/DHCP/NTP/SSDP/mDNS/HTTP/HTTPS/SSH/SMTP…)—— 可导出**标准 pcap 文件**,直接用 Wireshark 打开分析
- **局域网 Web 控制台**:内置 HTTP 服务器 —— 电脑浏览器看全部报告、下载原始 CSV 与 pcap、实时抓包统计、**远程触发扫描**(仅限局域网)
- **实时监测**:传感器示波器(加速度/陀螺/磁力/光照/温度/气压/噪声)、**姿态水平仪**(互补滤波气泡盘,roll/pitch/稳定度)、音频**频谱瀑布图**(FFT)、阈值告警通知(噪声/温度/光照)
- **传感器 RAW 录制器**:最高采样率录制加速度/陀螺/磁力/旋转矢量/气压原始流到 CSV,带实时多通道波形与采样率计数
- **传感器标定向导**:磁力计 8 字标定(硬铁偏移)、加速度计重力基准、陀螺仪零偏 —— 输出可分享的校准参数报告
- **NFC 卡片分析器**:读卡模式识别 ISO 14443A/B、ISO 15693、FeliCa → UID/ATQA/SAK、Mifare Classic/Ultralight/NTAG/DESFire 类型识别、**Mifare 默认密钥安全审计**(KeyA+KeyB 逐扇区、未锁扇区完整转储)、NDEF 解析(TEXT/URI/智能海报)、**NDEF 写入器**(仅限自己的测试标签)、风险评级(INFO/LOW/HIGH)
- **HCE 卡模拟器**:HostApduService(AID F0010203040506)响应 SELECT/READ/GET_UID,测试自己拥有的读卡器
- **安全审计引擎**:聚合全部安全探测(端口/TLS/证书/HTTP/WiFi/SMB/MQTT/SSH)→ 分级(INFO→CRITICAL)审计报告,应用内展示并可分享 Markdown
- **协议深探**:TLS 协商密码套件/协议版本/ALPN 提取、SSH 版本 banner、手写 SMB2 NEGOTIATE(dialect + 签名模式)
- **安全与渗透辅助**:局域网主机发现(OUI 厂商识别)、全子网扫描、端口扫描(服务识别)、服务 Banner 抓取、HTTP/TLS 指纹(Web 技术栈与证书分析)、HTTP 方法与安全头测试、TLS 版本探测、MQTT Broker 探测、Web 路径枚举、并发连接测试、NTP 时间偏移、SSDP/UPnP 设备发现、DNS 解析测试、TCP 连通性测试 —— 目标主机可配置(默认网关)
- **数据包发送器**:自定义 UDP/TCP 十六进制载荷,响应 HEX/ASCII 回显 —— 用于对授权目标的协议测试
- **抓包增强**:TLS 版本分布(ClientHello)+ QUIC(UDP/443)检测 + IP 流量 TOP 排行
- **硬核网络检测**:**DNS 劫持检测**(自写 DNS 客户端,多解析源一致性对比,超时与 NXDOMAIN 区分)、**ARP 欺骗检测**(网关 MAC 变化监控)、**ARP 邻居表**(/proc/net/arp,重复 MAC 与厂商分析)、**DNS-over-HTTPS 探测**(加密解析,延迟与证书检查)、**QUIC 连通性探测**(手写 QUIC Initial,UDP 443)、**mDNS 服务发现**、**UPnP 设备深度解析**(描述 XML:类型/服务/序列号)、**音频链路回环测试**(扬声器→麦克风延迟)
- **网络诊断**:**Ping 监视器**(持续 TCP ping,延迟/抖动/丢包序列图)、**网络测速**(Cloudflare 边缘节点,延迟+抖动 / 20MB 下载 / 16MB 上传,Mbps 实时读数与评级)、**网络健康矩阵**(网关/DNS/公网并行监测,雷达矩阵图)
- **移动诊断**:**GPS 轨迹记录**(1Hz 轨迹,里程/速度统计,速度着色轨迹图,KML/CSV 导出)、**电池放电曲线**(电压/电流/温度曲线,放电速率 %/h、功耗 W、剩余续航估算)、**WiFi 信号地图**(位置+RSSI 采样点 → 热力图)、**GNSS 卫星天空图**(方位/仰角极坐标,星座分色,C/N0 排行)、**蓝牙深度分析**(每设备 RSSI 分布、OUI 厂商识别、BLE/经典分类)
- **系统深层分析**:网络连接表、内核内存明细、逐核 CPU 使用率、磁盘 IO 统计、开机与运行统计
- **校准与电气分析**:校准/未校准传感器偏差分析(磁硬铁偏移)、电池放电速率与续航估算、WiFi 信道拥挤度分析
- **连续监测**:前台服务定时测量,质量趋势图 + **趋势推断**(显著上升/下降/平稳判定)
- **主题与交互**:Material 3 动态取色(Android 12+ 可开关,默认品牌配色)、系统/浅色/深色切换、图表触摸十字线读数、主要操作触觉反馈、测量期间屏幕常亮、下拉刷新
- 界面中英双语(跟随系统语言)

## 构建

```
# 环境要求: JDK 17+, Android SDK 36
./gradlew assembleRelease     # 产物: app/build/outputs/apk/release/VicinityProbe-<version>.apk
./gradlew testDebugUnitTest   # 单元测试(统计/FFT/分析/融合/TLS/NFC)
./gradlew lint                # 静态检查
```

## 权限

定位、邻近 WiFi 设备、蓝牙扫描/连接、麦克风、NFC、红外、活动识别、生物传感器、通知、前台服务。每项权限的用途都在应用里写明,可以单独拒绝;被拒绝的探测项会在报告里标 `PERMISSION_DENIED`,不会中断整个测量。

> **合规声明**:请遵守当地法律法规合法使用本软件,使用方式由使用者自行负责。
>
> **标注了合规风险的探测项**:下面这些测出来的数据,在部分国家和地区可能受法律约束,或属于个人数据,应用内和报告里都会用 ⚠️ 标出来:WiFi 扫描 / RTT 测距 / Direct / Aware、蓝牙扫描 / 经典发现 / 已配对列表、蜂窝网络与小区标识、位置与 GNSS(含原始观测量)、麦克风声压级、NFC、心率、设备序列号,以及主动网络探测(主机发现 / 端口扫描 / HTTP-TLS 指纹 / SSDP / DoH / QUIC)。详见 [docs/PROBES.zh-CN.md](docs/PROBES.zh-CN.md) §7.5。
>
> **NFC 安全测试范围**:NFC 分析器只读取标签元数据并审计**默认密钥可访问性**(不做密钥恢复、不做克隆);NDEF 写入器与 HCE 模拟器仅用于**你自己拥有的标签和读卡器**。破解他人卡片属违法行为,请负责任地测试。

## 已知边界(报告里会如实注明)

- 声压级是**未校准的参考值**(要绝对声级得做设备级校准)
- thermal、CPU 频率这些 `/sys` 文件,多数设备上应用读不了
- WiFi 扫描受系统节流限制
- 没有遥测、没有云同步,数据全部留在本机;主动网络探测(端口扫描/抓包/DNS 对比/局域网发现…)只在你自己触发时运行
- **硬件边界**:手机没有 125kHz RFID 天线,Mifare 离线密钥破解与射频嗅探需要专用硬件工具
