# VicinityProbe

用手机上的各种传感器和系统模块,按规范采集周边环境数据,生成带质量评估、原始样本存档和频谱分析的测量报告。

[English](README.md) · [探测体系文档](docs/PROBES.zh-CN.md)

## 功能

- **测量目录(61 项)**:每项探测都是正式的 `ProbeSpec` 条目,写明被测量、SI 单位、标称采样率、量程——覆盖运动、环境物理量、磁场、生物信号、声学、定位与卫星、无线电、电气、系统资源、设备信息、上下文事件
- **能力预检**:开始前先检查设备支持情况(✅ 可用 / ⚠️ 缺权限 / ❌ 无硬件),自己挑要测的项目
- **数据质量门禁**:每项测量给出 EXCELLENT/GOOD/DEGRADED/FAILED 等级,附带采样覆盖率和实际采样率,原因码可机读
- **专业统计**:每个通道输出 min/max/mean/stddev/RMS/CV,以及 p1/p5/p25/p50/p75/p95/p99 分位数
- **声学**:直接用 AudioRecord 采 PCM,算 LAeq / Lpeak / L10 / L50 / L90
- **频谱分析**:自带 Radix-2 FFT(Hann 窗),输出主导频率、频谱平坦度、频带能量
- **振动分析**:主导频率 / RMS / 峰值因子 / ISO 2631 近似分级
- **原始样本存档**:所有数值通道都落盘成 CSV(`samples/<probeId>/channel_<ch>.csv`)
- **报告导出**:JSON + Markdown + ZIP(报告和原始样本一起打包)
- **历史与对比**:报告存档、重命名、删除,两份报告逐项对比
- **连续监测**:前台服务定时测量,看质量趋势图
- 界面中英双语(跟随系统语言)

## 构建

```
# 环境要求: JDK 17+, Android SDK 36
./gradlew assembleRelease     # 产物: app/build/outputs/apk/release/VicinityProbe-<version>.apk
./gradlew testDebugUnitTest   # 单元测试(统计/FFT/分析/报告)
./gradlew lint                # 静态检查
```

## 权限

定位、邻近 WiFi 设备、蓝牙扫描/连接、麦克风、活动识别、生物传感器、通知、前台服务。每项权限的用途都在应用里写明,可以单独拒绝;被拒绝的探测项会在报告里标 `PERMISSION_DENIED`,不会中断整个测量。

> **合规声明**:请遵守当地法律法规合法使用本软件,使用方式由使用者自行负责。
>
> **标注了合规风险的探测项**:下面这些测出来的数据,在部分国家和地区可能受法律约束,或属于个人数据,应用内和报告里都会用 ⚠️ 标出来:WiFi 扫描 / RTT 测距 / Direct / Aware、蓝牙扫描 / 经典发现 / 已配对列表、蜂窝网络与小区标识、位置与 GNSS(含原始观测量)、麦克风声压级、NFC、心率、设备序列号。详见 [docs/PROBES.zh-CN.md](docs/PROBES.zh-CN.md) §7.5。

## 已知边界(报告里会如实注明)

- 声压级是**未校准的参考值**(要绝对声级得做设备级校准)
- thermal、CPU 频率这些 `/sys` 文件,多数设备上应用读不了
- WiFi 扫描受系统节流限制
- 所有数据都在本地处理,完全不联网(没有遥测,没有云同步)
